# Security Policy

## Supported Versions

Kami secara aktif merilis pembaruan keamanan untuk versi stabil terbaru EugineBill:

| Version | Supported          |
| ------- | ------------------ |
| 2.39.x  | :white_check_mark: |
| 2.38.x  | :white_check_mark: |
| < 2.38  | :x:                |

## Melaporkan Kerentanan Keamanan (Vulnerability Reporting)

Jika Anda menemukan potensi celah keamanan (vulnerability) pada sistem EugineBill, mohon **JANGAN** membuat issue publik di GitHub.

Silakan laporkan temuan Anda secara privat melalui:
- **Email Tim Pengembang**: `security@euginemediagroup.com` atau kontak langsung tim pengembang.
- Mohon sertakan:
  1. Deskripsi celah keamanan dan potensi dampaknya.
  2. Langkah-langkah detail untuk mereproduksi (PoC).
  3. Saran mitigasi jika tersedia.

Tim kami akan mengkaji laporan dan merilis patch perbaikan keamanan secepatnya.
